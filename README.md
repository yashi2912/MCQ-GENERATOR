# 🧠 MCQ-GENERATOR

A Flask-based MCQ Generator that creates multiple-choice questions dynamically.

## 🚀 Features
- Generate MCQs by Topic (Python, SQL, Data Analyst)
- Difficulty: Easy/Medium/Hard
- Auto correct answer + Print PDF

## 🛠️ Run
pip install -r requirements.txt
python app.py
